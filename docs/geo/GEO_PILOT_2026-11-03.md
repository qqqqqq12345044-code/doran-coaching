# DORAN GEO/AEO 1차 파일럿 운영 문서 (2026-11-03)

작업 브랜치: `work/geo-aeo-pilot-2026-11-03` (base: `origin/main` a2644d7). work 브랜치에만 반영하며 main merge·Production 배포는 하지 않는다(별도 승인 전까지).

## 1. 목적과 범위

- 목표: 검색엔진이 찾고, 질문에 "답"으로 읽히기 쉽고, 생성형 AI 답변의 **후보가 될 가능성을 높이는** 구조로 질문형 콘텐츠를 정리한다.
- 이번 범위: 질문형 파일럿 페이지 8개 + 3개 언어 랜딩 최소 개선 + 내부링크 + Prompt Audit 질문 목록 + 검증 스크립트.
- 하지 않은 것: 대량 생성, 지역 페이지 확장, 새 route/컴포넌트 시스템, 새 패키지, 새 이미지·영상, 새 JSON-LD 타입, 분석 시스템 신설.

## 2. 표현 원칙 (이 작업 전체에 적용)

| 허용 | 금지 |
|---|---|
| "AI가 인용하기 쉬운 구조" | AI 인용·노출·상위노출 보장 표현 |
| "AI 답변의 후보가 될 가능성을 높이는 구조" | "이렇게 쓰면 네이버 AI 브리핑 상위노출" 같은 보장성 문구 |
| 질문 → 직접 답변 → 선택 기준 → 근거와 한계 → 주의점 → 도란 서비스 연결 | "정답은 도란입니다" 같은 광고성 결론 |

- 사람이 읽는 페이지 본문에는 AI·인용·노출 관련 언급을 쓰지 않는다. `validate:geo-pilot`이 금지어를 검사한다.

## 3. GEO 연구 수치 해석 주의

교육자료에 나온 "최대 약 40%"는 **트래픽·매출·검색순위가 40% 늘어난다는 뜻이 아니다.** 통제된 실험에서 일부 전략이 "생성형 답변 안의 가시성 지표"를 개선한 폭이다. 이 문서·페이지·보고에서 숫자를 쓸 때는 (1) 어떤 지표인지 (2) 출처 (3) 한계(실험 조건, 우리 사이트에 그대로 적용된다는 근거 없음)를 함께 적는다. 원문 출처는 교육자료 외에 이 작업에서 직접 확인하지 못했으므로, 외부에 인용하려면 원문을 먼저 확인해야 한다. 이번 페이지 본문에는 이 수치를 쓰지 않았다.

## 4. 구조 결정: 기존 매거진 재사용

기존 `/magazine/[slug]`가 이미 질문(directAnswer) → 본문 → 관련 링크 → FAQ → 상담 CTA 구조, Article/FAQPage/BreadcrumbList JSON-LD, canonical, sitemap shard 0, RSS를 갖고 있다. 그래서 새 route·컴포넌트를 만들지 않고 데이터 파일 `data/magazine/geoPilot.ts`에 8개를 추가했다.

- 신규 URL 8개 (`dynamicParams = false` 화이트리스트, 기존 sitemap shard 0에 자동 포함). 지역(local) 구조·sitemap 규칙은 변경하지 않았다.
- 페이지 구성: H1(질문) → 즉답 박스(2~4문장) → ① 핵심 요약 → ② 상세/선택 기준 → ③ 근거와 한계 → ④ 흔한 오해와 주의점 → ⑤ 도란 서비스 연결 → 관련 과정/관련 글 → FAQ(3~4) → 상담 CTA.

## 10. 측정 (3축 + 판단 원칙)

GEO 성공 여부를 "AI 인용 여부 하나"로 판단하지 않는다. 사이트 규모가 작아 생성형 AI 관련 데이터가 보이지 않아도 실패로 간주하지 않는다.

1. **Search Console — 노출·클릭**: 성능 보고서 → 페이지 → URL 필터 `/magazine/` 중 위 8개 URL. 쿼리 필터로 질문형 키워드(예: 화상영어 주 몇 회) 확인. 색인 상태는 URL 검사. 신규 URL이라 비교 기준선은 게시 후 첫 28일.
2. **GA4 — 방문·상담·전환**: `main`(a2644d7)에는 GA4 코드가 없다(확인함). GA4 컴포넌트(`GoogleAnalytics.tsx`)는 통합 브랜치 `work/doran-integration-2026-10-30`에만 있고 Production 반영 여부는 사용자 확인이 필요하다. GA4가 연결되면 페이지 경로 `/magazine/<slug>` 8개로 방문, 상담폼 제출·전화 클릭 이벤트와 연결한다. 현재 `main`의 상담폼은 `lib/attribution.ts`가 수집한 최초 유입 페이지(landingPage)·UTM·referrer를 상담 시트의 "최초 유입 페이지"·utm_*·referrer 열에 함께 저장하므로, "최초 유입 페이지"가 `/magazine/<slug>`로 시작하는 상담 건을 수작업으로 셀 수 있다(질문 글에서 시작한 방문 기준이며, 명시적 UTM 유입이 새로 생기면 최초 유입 값이 갱신되는 규칙이 있다).
3. **Prompt Audit — 브랜드 언급·출처 인용**: `docs/geo/prompt-audit-questions-2026-11.csv`(질문 13개: 파일럿 8 + 기존 글 3 + 브랜드 기준선 2)를 ChatGPT / Google AI 개요·AI 모드 / 네이버 AI 등에서 **같은 문구로 반복** 질의하고 `docs/geo/prompt-audit-results-log.csv` 형식으로 기록한다(실행일, 질문 ID, 플랫폼, 브랜드 언급 Y/N, 출처 인용 Y/N, 인용 URL, 답변이 페이지 내용과 일치하는지). 로그인 상태·지역·시점에 따라 답이 달라지므로 같은 조건으로 4주 간격 등 일정한 주기로만 비교한다. 게시 직후에는 반영되지 않았을 수 있다.

판정 규칙: 세 지표를 따로 기록하고, 어느 하나의 부재만으로 결론 내리지 않는다. 확장 판단은 "Search Console 노출·클릭이 늘고 상담 연결이 있는 주제"를 우선한다.

## 11. 광고와 GEO 분리

네이버 검색광고 집행 여부와 AI 인용·자연노출은 **별도 성과**로 본다. 광고 집행이 AI 인용을 높인다고 가정하지 않으며, 광고 랜딩의 CTA·전환 구조는 변경하지 않았다. 광고 유입(UTM)과 자연 유입은 attribution(`utm_source`, `referrer`, `landingPage`)로 구분해서 본다.

## 12. 사용자 확인이 필요한 사실

repo에서 확인되지 않아 **사실처럼 쓰지 않고 "상담에서 안내"로만 연결**한 항목: 1회 수업 길이(30분 가능 여부 포함), 주당 횟수 옵션, 체험 수업 여부, 일정 변경·환불 규정, 교재 포함 여부, 수강료. 이 정보를 공개해도 되면 알려주면 각 글의 "도란에서는…" 섹션에 사실로 반영하고 `updatedAt`을 입력한다.
